AQORBOX Android (AdMob) - cara pakai singkat
1. Buat repo baru di github.com, unggah SEMUA berkas di folder ini (termasuk folder .github).
2. Buka tab Actions > "Build AQORBOX APK" > Run workflow.
3. Setelah hijau, buka run-nya, unduh artefak "aqorbox-apk" (zip berisi app-debug.apk), pasang di HP.
4. Ganti isi admob_app_id.txt dengan App ID AdMob asli kamu sebelum rilis.
